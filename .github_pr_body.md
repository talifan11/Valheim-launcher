## Редизайн главного экрана: двухколоночный layout в стиле Battle.net

### Что сделано
- Layout 65/35: лента новостей слева, панель сервера/персонажа справа
- Прямоугольная золотая кнопка ИГРАТЬ вместо круглой (64px, градиент #d4af37)
- Новые компоненты: NewsFeed, NewsCard, ServerPanel, PlayButton, screens/MainScreen
- Mock-данные 5 новостей в src/data/news.ts с градиентными fallback при отсутствии картинок
- Шрифт JetBrains Mono для адреса сервера (pgsql-louisville.tun.ply.gg:21589, копирование в 1 клик)
- Фиксы сборки по чек-листу: чистый JSON в capabilities/default.json, watch.ignored для src-tauri в vite.config.ts
- Плейсхолдеры public/backgrounds/main.jpg и public/news/*.jpg (положить свои картинки)

### Как проверить
```bash
npm install
npm run tauri dev
```

### Критерии готовности
- Главный экран двухколоночный, слева скроллится лента из 5 новостей
- Справа: статус сервера, персонаж, прямоугольная кнопка ИГРАТЬ, настройки
- Без картинок работают градиентные плейсхолдеры

# Редизайн главного экрана в стиле SIRUS/Steam

## Что сделано
- Sidebar (200px): статус сервера, адрес с копированием, игроки онлайн, настройки
- TopNav: табы Новости / События / Моды / Аккаунт с золотым подчёркиванием
- HeroCard: большие карточки новостей с фото-фоном и градиентной вуалью
- EventsFeed: компактная лента событий
- BottomBar: статус + «Проверить клиент» + умная кнопка (Играть/Установить/Обновить/Повторить) по фазе обновления
- App.tsx: состояние connection прокинуто между ServerPanel и TitleBar
- Исправлен битый импорт в InstallScreen, возвращена кнопка «Открыть папку игры»
- Из репозитория вычищены node_modules/, dist/, архивы; обновлён .gitignore

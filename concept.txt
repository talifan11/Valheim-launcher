## Общая картина

**Valheim Rouge** — игровой проект:
- **Лаунчер** (Tauri + React) — игроки логинятся, обновляют клиент, играют, общаются

- **API** (FastAPI на VPS) — обслуживает всё
- **Игровой сервер** (Valheim + BepInEx) — на ПК владельца
- **Сайт-креативы** — отдельный репо

## Рабочие процессы

### Выкатить новую версию лаунчера

**Старый способ (SSH):**
1. Бамп версии (package.json, tauri.conf.json, config.ts)
2. rm -rf dist node_modules/.vite
3. npm run build
4. taskkill /F /IM valheim-rouge.exe
5. npm run tauri build
6. scp exe на VPS

**Новый способ (DevOps Panel):**
1. Бамп версии локально + git push
2. Открыл админку → DevOps → Команды → «Собрать лаунчер»
3. Ждёшь 5-10 минут
4. Открываешь админку → Лаунчер → загружаешь exe
5. Готово!

**ВАЖНО:** имя exe без пробелов! `ValheimRouge_1.0.18_x64-setup.exe`

### Загрузить моды

1. Положить .dll в `Z:\ValheinRogue\valheimClient\BepInEx\plugins\`
2. DevOps Panel → «Синхронизировать клиент»
3. Моды → Манифест → версия `1.0.X` → Пересобрать

### Опубликовать новость

Админка → Новости → Новая → сохранить → Правка → загрузить картинку.
Игроки видят через 1 минуту (кэш) или при возврате фокуса в лаунчер.

### Применить патч бэка

**Старый:** ssh → nano main.py → сохранить → systemctl restart valheim-api

**Новый:** DevOps → Патчи → вставить Python-код → «Применить патч»
Авто-бэкап + авто-откат при ошибке + рестарт.

## Local Bridge (devops_bridge.py)

**Что делает:** слушает очередь команд на VPS, выполняет на ПК.

**Запуск:** двойной клик `devops_bridge.bat` в `Z:\ValheinRogue\`.

**Токен:** установлен на VPS, прописан в `devops_bridge.py`.

**Shell:** автоматически ищет Git Bash (`Z:\Git\bin\bash.exe`).

**Whitelist команд** (только они могут выполняться):
- `build-admin` — npm run build + scp
- `build-launcher` — Tauri build
- `sync-client` — заливка плагинов
- `git-push-admin` — commit + push admin
- `git-push-launcher` — commit + push launcher

**Фичи:**
- Асинхронное выполнение (threading) — ping не блокируется во время сборки
- Auto-register на VPS при старте
- Проверка синтаксиса патча перед применением
- Auto-rollback бэкапа main.py при ошибке
